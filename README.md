# Arnab Maharjan — Personal Portfolio

> Building interfaces that actually work.

A personal portfolio website showcasing my work, skills, projects, and journey as a BCA student interested in **UI/UX Design, Front-End Development, and Quality Assurance (QA)**.

The website features a modern dark aesthetic, clean typography, responsive layouts, and interactive elements designed to create a smooth browsing experience.

## 🌐 Live Website

**Portfolio:** [View Live Portfolio](https://arnab213-max.github.io/)

## ✨ Features

- **Personal Introduction** — Overview of my background, interests, and goals.
- **About Me** — Information about my journey and development interests.
- **Skills & Expertise** — Highlights of my design, development, and QA interests.
- **Resume / CV** — View or download my CV.
- **Selected Projects** — Showcase of my web development and design projects.
- **Interactive Project Showcase** — Explore project details through interactive modals.
- **Blog Section** — Articles about coding, UI/UX design, QA, and learning experiences.
- **Responsive Navigation** — Smooth section navigation and a mobile menu.
- **Contact Section** — Ways to connect and discuss opportunities.
- **Modern UI** — Dark theme, subtle animations, and a black, green, and red color palette.

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure.
- **CSS3** — Responsive layouts, styling, animations, and CSS Grid.
- **JavaScript** — Interactive components, navigation, project showcases, and blog filtering.
- **Google Fonts** — Fraunces, Inter, JetBrains Mono, and Caveat.
- **Font Awesome** — Icons and interface elements.
- **Git & GitHub** — Version control and project hosting.

## 🚀 Run Locally

No framework or package installation is required for the basic portfolio.

1. Clone the repository:

   ```bash
   git clone https://github.com/Arnab213-max/Arnab213-max.github.io.git
   ```

2. Open the project folder:

   ```bash
   cd Arnab213-max.github.io
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
